A quiet macOS utility

Review large files.
Keep what matters.

Choose folders, see the local files taking up space, and decide what belongs in Trash.

A clear, deliberate workflow

  1. Choose the folders you want to review.
  2. Scan using a minimum file size.
  3. Review names, sizes, dates, and locations.
  4. Select files and confirm before moving them to Trash.

Moving files to Trash does not immediately free disk space. Restore files by moving them from Finder’s Trash back to a folder.

Made for local documents

The Mac App Store edition excludes apps, Library data, hidden files, symbolic links, and cloud-backed files. It does not uninstall apps, clean system caches, or empty Trash.

Your files stay on your Mac

No account, advertising, or analytics SDKs. File review happens locally. Read the privacy policy.

Requires macOS 14 or later. Get help using Cleanup.
