Help with Cleanup

Support

Scan a folder

Click Choose Folders and select a local documents folder. Pick a minimum size, then click Scan. Changing the minimum size clears the previous results; scan again to apply it.

Review before removing

Select file rows to see the matching total. Reveal opens their location in Finder. Move to Trash asks for confirmation. Failed items stay visible with an explanation.

Search, sort, and preview

Search filters filenames. Clearing the search shows all results again, but does not reselect files hidden by the search. Select All applies to visible results. Use the Sort menu to compare files by size, name, or modification date. Select one file and click Quick Look, or press Space while the table has focus. Reveal opens the selected files in Finder.

A file changed after scanning

Scan again before moving the file. Cleanup checks file size and modification date before moving it to Trash. Files that changed remain visible with an explanation. If only some files move successfully, review the remaining issues before trying again.

Restore a file

Open Trash in Finder and move the file to the folder where you want to keep it. Finder may not offer Put Back for files moved by Cleanup. Cleanup does not empty Trash.

Resolve folder access issues

Reconnect removable storage if necessary. If a saved folder no longer opens, choose Forget Folders, then select the folders again. An incomplete scan does not mean inaccessible folders are empty.

What is excluded?

The Store edition reviews ordinary local documents. It skips apps, Library/system data, hidden files, symbolic links, and cloud-backed files.

Contact support

Open a support issue on GitHub, or browse existing issues. A GitHub account is required to open an issue. Issues are public.

Please describe the issue, macOS version, and Cleanup version. Do not share passwords, private files, or screenshots containing personal information.
